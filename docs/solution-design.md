### 4.2. Tecnologias

_Para o desenvolvimento deste projeto, será utilizado um conjunto de tecnologias modernas e amplamente adotadas no mercado, cobrindo todas as camadas da aplicação.

No banco de dados, será utilizado o MySQL (versão 8.x), um sistema de gerenciamento de banco de dados relacional robusto, eficiente e de fácil integração com aplicações Java.

No front-end, serão empregadas as linguagens padrão da web: HTML, CSS e JavaScript (ES6+), responsáveis pela estrutura, estilização e interatividade da interface do usuário.

No back-end, será utilizado Java (versão 17 LTS), em conjunto com o framework Spring Boot (versão 3.x), que facilita a criação de APIs REST, gerenciamento de dependências e configuração da aplicação.

Como ambiente de desenvolvimento, será utilizado o Visual Studio Code, um editor leve e extensível, com suporte a diversas linguagens e integração com ferramentas modernas de desenvolvimento.

Para controle de versão, serão utilizados Git e a plataforma GitHub, permitindo o versionamento do código, colaboração e gerenciamento do projeto.

Por fim, o deploy da aplicação será realizado na plataforma Vercel, que oferece hospedagem simplificada e integração contínua para aplicações web, especialmente voltadas ao front-end._
